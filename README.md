# Tower Defense Path Editor

Tower Defense Path Editor is a local-first, browser-based editor for creating tower defense
level paths. It has no backend, account system, or runtime network dependency. The project is in
an early development phase; Phase 0 establishes its frontend tooling only.

## Technology stack

- Vue 3
- TypeScript
- Vite
- Pinia
- Zod
- Vitest

## Development

Install dependencies with npm:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Other useful commands:

```bash
npm run build
npm run test:run
npm run lint
npm run typecheck
npm run check
```

The editor functionality is intentionally not implemented yet. Subsequent development phases will
add the core data model and editor capabilities.
